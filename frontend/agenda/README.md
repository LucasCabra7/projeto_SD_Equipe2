# Interface da agenda

Página em React, TypeScript e Ant Design, servida pelo Vite na porta 5173. Tudo que a página pede em `/api` o Vite repassa para o backend em `127.0.0.1:5050`.

```bash
npm install
npm run dev
```

Como rodar o sistema inteiro, inclusive em várias máquinas, está no [README da raiz](../../README.md).
